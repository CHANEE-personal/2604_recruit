# 프로젝트 가이드

Spring Boot 3.3.5 + Java 17 기반 헥사고날 아키텍처 구독 서비스.

## .claude/ 파일 로드 기준

| 태스크             | 로드할 파일                                                                       |
|-----------------|------------------------------------------------------------------------------|
| 코드 리뷰 (파일/패키지)  | `review-guide.md` + `review-hexagonal.md` (+ `mapping-guide.md` Mapper 포함 시) |
| 패키지/파일 생성       | `generate-guide.md`                                                          |
| 런타임 디버깅/검토      | `runtime-guide.md`                                                           |
| MapStruct 매핑 검토 | `mapping-guide.md`                                                           |
| MVC 구조 리뷰       | `review-guide.md` + `review-mvc.md`                                          |
| 테스트 코드 작성/리뷰    | `test-guide.md`                                                              |

> 태스크에 해당하지 않는 파일은 로드하지 않는다.
